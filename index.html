StatsToo

バスケットボールをデータで、もっと楽しく。

FEATURES

主な機能

📊

リアルタイム記録

試合中にタップするだけで各選手のスタッツを簡単に記録。シュート、リバウンド、アシストなど全項目対応。

📈

チーム比較

両チームのスタッツをグラフで視覚的に比較。シュート成功率や各項目の差を一目で確認できます。

📸

画像シェア

Box ScoreやTeam Comparisonを画像で出力。SNSで試合結果をシェアしたり、保存して振り返りに活用。

TOOLS

ツール一覧

📊

試合スタッツ記録

試合中にリアルタイムでスタッツを記録・分析。Box Score、チーム比較、CSV出力など充実の機能。

→
🎯

個人練習ツール 開発中

シューティング練習の成果を記録・管理。自主練の成果を可視化して上達をサポート。

🗺️

ショットチャート 開発中

コート上のシュート位置を可視化。得意エリア・苦手エリアを分析して練習に活かせます。

📝

バスケコラム 執筆中

バスケットボールに関する記事・コラム。ルール解説やスキル用語の説明など。

HOW TO USE

使い方

1

メンバーを登録

「メンバー編集」で選手名を入力。コート上の5人をチェックで選択します。

2

選手を選んでスタッツ記録

選手をタップして選択し、下部のボタンでスタッツを記録。シュート、リバウンド、アシストなど。

3

結果を確認・シェア

Box Scoreで全選手のスタッツを確認。画像生成でSNSシェアやCSV出力も可能です。
